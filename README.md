# Brechó Moonlight | Landing page

Site institucional estático, responsivo, pronto para GitHub Pages. Não exige npm, servidor ou build.

## Configurar os contatos

Abra `script.js` e altere:

- `instagram: 'SEU_USUARIO_INSTAGRAM'` para o usuário real, sem @.
- `whatsapp: '55DDDNUMERO'` para o número real, com DDI 55 e DDD, sem espaços ou sinais.

Enquanto não forem configurados, os botões exibem um aviso em vez de enviar visitantes para contatos incorretos.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (`index.html`, `style.css`, `script.js` e `assets/`).
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois **Save**.
6. Acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/` após a publicação.

## Personalização

- A imagem da logo está em `assets/logo-moonlight.png`.
- A paleta e o layout ficam em `style.css`.
- As imagens editoriais de moda são ilustrativas, carregadas do Unsplash; substitua por fotos autorizadas da loja antes da entrega.
- A política de trocas/devoluções no site foi redigida com ressalva aos direitos previstos na legislação brasileira. Confirme a política real com a loja.

O site apresenta a marca e encaminha clientes ao Instagram/WhatsApp; **não** inclui catálogo com cadastro de produtos, checkout ou painel administrativo.
